## 1. 🧱 Основы

**Вероятность** — это число от 0 до 1, показывающее, насколько вероятно событие.

$$P(A) = \frac{\text{Желаемые исходы}}{\text{Всего исходов}}$$

- **P = 0**: Событие невозможно
- **P = 0.5**: 50% шанс
- **P = 1**: Событие точно произойдет

Можно также выражать в процентах.


### Пример: бросок кубика

```go
// Вероятность выпадения 6
// Желаемые исходы: 1 (только шестерка)
// Всего исходов: 6 (от 1 до 6)

func rollDice() int {
    return rand.Intn(6) + 1 // Генерирует от 1 до 6
}
```

## 2. 🔗 Зависимые и независимые события


### Независимые события

Одно событие **не влияет** на другое.

**Формула:** $P(A \text{ и } B) = P(A) \times P(B)$

**Пример**: Бросок монеты дважды
- Вероятность выпадения "Орел" два раза подряд: $\frac{1}{2} \times \frac{1}{2} = \frac{1}{4} = 0.25$

```go
func flipCoin() string {
    if rand.Intn(2) == 0 {
        return "Орел"
    }
    return "Решка"
}

func main() {
    heads := 0
    trials := 10000
    
    for i := 0; i < trials; i++ {
        if flipCoin() == "Орел" && flipCoin() == "Орел" {
            heads++
        }
    }
    
    probability := float64(heads) / float64(trials)
    fmt.Printf("P(два орла) ≈ %.3f (ожидается 0.250)\n", probability)
    // Вывод: P(два орла) ≈ 0.250
}
```

---


### Зависимые события

Одно событие **влияет** на другое.

**Пример**: Вытянули 2 карты из колоды **без возврата**
- Вероятность вытянуть 2 туза:
  - Первый туз: $\frac{4}{52}$
  - Второй туз (если первый был туз): $\frac{3}{51}$ (осталось 3 туза из 51 карты)
  - $P = \frac{4}{52} \times \frac{3}{51} \approx 0.0045$

```go
func drawTwoAces() bool {
    deck := make([]string, 52)
    for i := 0; i < 4; i++ {
        deck[i] = "Туз" // 4 туза
    }
    for i := 4; i < 52; i++ {
        deck[i] = "Другая карта"
    }
    
    // Перемешиваем
    rand.Shuffle(len(deck), func(i, j int) {
        deck[i], deck[j] = deck[j], deck[i]
    })
    
    // Берем две карты
    return deck[0] == "Туз" && deck[1] == "Туз"
}

func main() {
    successes := 0
    trials := 100000
    
    for i := 0; i < trials; i++ {
        if drawTwoAces() {
            successes++
        }
    }
    
    probability := float64(successes) / float64(trials)
    fmt.Printf("P(два туза) ≈ %.4f (ожидается 0.0045)\n", probability)
    // Вывод: P(два туза) ≈ 0.0045
}
```

## 3. 📈 Ожидаемое значение (Expected Value)

**Ожидаемое значение** — это средний результат при множестве повторений.

$$E[X] = \sum (x_i \cdot P(x_i))$$


### Пример: бросок кубика

Какое число в среднем выпадет?

$$E[X] = 1 \cdot \frac{1}{6} + 2 \cdot \frac{1}{6} + 3 \cdot \frac{1}{6} + 4 \cdot \frac{1}{6} + 5 \cdot \frac{1}{6} + 6 \cdot \frac{1}{6} = \frac{21}{6} = 3.5$$

```go
func testExpectedValue() {
    sum := 0
    trials := 100000
    
    for i := 0; i < trials; i++ {
        sum += rand.Intn(6) + 1 // От 1 до 6
    }
    
    average := float64(sum) / float64(trials)
    fmt.Printf("Среднее значение: %.2f (ожидается 3.50)\n", average)
    // Вывод: Среднее значение: 3.50
}
```

---


### Применение: оценка рисков

**Пример**: Стоит ли покупать лотерейный билет за 100 рублей?
- Приз 1,000,000 рублей с вероятностью 1/100,000
- Приз 10,000 рублей с вероятностью 1/10,000
- Иначе 0 рублей

$$E[\text{выигрыш}] = 1{,}000{,}000 \cdot \frac{1}{100{,}000} + 10{,}000 \cdot \frac{1}{10{,}000} = 10 + 1 = 11 \text{ рублей}$$

Вы платите 100 рублей, а ожидаете получить **11 рублей** — невыгодно! 📉

## 4. 🎯 Симуляция Монте-Карло

**Метод Монте-Карло** — использование случайных чисел для решения математических задач.


### Пример: вычисление числа π

Идея: бросаем случайные точки в квадрат 1×1, считаем, сколько попало в четверть круга.

$$\frac{\text{Точек в круге}}{\text{Всего точек}} \approx \frac{\pi}{4}$$

```go
func estimatePi(trials int) float64 {
    insideCircle := 0
    
    for i := 0; i < trials; i++ {
        // Случайная точка (x, y) в квадрате [0, 1] × [0, 1]
        x := rand.Float64()
        y := rand.Float64()
        
        // Проверяем, в круге ли точка: x² + y² ≤ 1
        if x*x+y*y <= 1.0 {
            insideCircle++
        }
    }
    
    // π/4 ≈ insideCircle / trials
    // π ≈ 4 * (insideCircle / trials)
    return 4.0 * float64(insideCircle) / float64(trials)
}

func main() {
    trials := 1000000
    pi := estimatePi(trials)
    fmt.Printf("Оценка π ≈ %.5f (реальное π ≈ 3.14159)\n", pi)
    // Вывод: Оценка π ≈ 3.14159
}
```

**Применение Монте-Карло:**
- Физика (симуляция частиц)
- Финансы (оценка рисков)
- Машинное обучение
- Игры (AI противники)

---


### Пример: симуляция игры

**Задача**: Какова вероятность выиграть в игре, если нужно выбросить сумму 7 или 11 на двух кубиках?

```go
func rollTwoDice() int {
    return rand.Intn(6) + 1 + rand.Intn(6) + 1
}

func winGame() bool {
    sum := rollTwoDice()
    return sum == 7 || sum == 11
}

func simulateGame(trials int) float64 {
    wins := 0
    
    for i := 0; i < trials; i++ {
        if winGame() {
            wins++
        }
    }
    
    return float64(wins) / float64(trials)
}

func main() {
    probability := simulateGame(100000)
    fmt.Printf("P(выиграть) ≈ %.3f\n", probability)
    // Теоретическая вероятность: 8/36 ≈ 0.222
    // Вывод: P(выиграть) ≈ 0.222
}
```

## 💡 Итог

| Концепция | Формула | Применение |
|:---|:---|:---|
| **Вероятность** | P = желаемые / всего | Оценка рисков, статистика |
| **Независимые** | P(A и B) = P(A) × P(B) | Множественные броски |
| **Ожидаемое значение** | E[X] = Σ(x·P(x)) | Оценка прибыльности |
| **Монте-Карло** | Симуляция N раз | Сложные вычисления |

> [!TIP]
> Используйте симуляции для **проверки** теоретических вероятностей или когда формулу сложно вывести!
