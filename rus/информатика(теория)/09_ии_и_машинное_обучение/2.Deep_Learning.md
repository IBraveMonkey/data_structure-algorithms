## 🖼️ CNN: Сверточные нейронные сети
Специализируются на данных с сеточной структурой (картинки).


### Анатомия свертки:
- **Filters (Ядра)**: Небольшие матрицы (например, 3x3), которые "скользят" по картинке.
- **Stride (Шаг)**: На сколько пикселей сдвигается фильтр. Большой шаг = меньше итоговая картинка.
- **Padding (Отступы)**: Добавление нулей по краям, чтобы сохранить размер картинки после свертки.
- **Receptive Field**: Область входного изображения, которую "видит" конкретный нейрон в глубоком слое.

**Слои:** `Conv -> ReLU -> Pooling (Max/Avg) -> ... -> Fully Connected`.

## 🔁 RNN: Рекуррентные сети и GRU
Используются для последовательностей (текст, аудио, временные ряды).


### Проблема долгой памяти
Обычные RNN страдают от **Затухающего градиента**. Они забывают начало длинного предложения.


### Решение: GRU (Gated Recurrent Unit)
Упрощенная и быстрая версия LSTM. Использует два типа ворот:
1.  **Update Gate**: Сколько старой информации пронести через время.
2.  **Reset Gate**: Какую часть прошлого забыть прямо сейчас.

## ⚡ Transformers: Новая эра (GPT, BERT)
Трансформеры отказались от последовательной обработки (как в RNN) в пользу параллельной.


### Почему они крутые?
RNN читает слова по порядку: `Я` -> `люблю` -> `Go`.
Трансформер видит **всё предложение сразу**. Это позволяет ему понимать связи между далекими словами.


### Позиционное кодирование (Positional Encoding)
Так как Трансформер видит всё сразу, он не знает порядка слов. Чтобы он понимал, что "Собака съела еду" и "Еда съела собаку" — это разное, к словам добавляются специальные векторы (синусоиды), кодирующие их позицию.

## 👁️ Attention Mechanism (Внимание)
Механизм, позволяющий модели фокусироваться на самом важном.

В **Multi-Head Attention** модель запускает несколько "голов" внимания параллельно. Одна голова может следить за грамматикой, другая за смыслом, третья — за связями между именами.

**Формула:** $Attention(Q, K, V) = softmax(\frac{QK^T}{\sqrt{d_k}})V$
- **Query (Q)**: Что я ищу.
- **Key (K)**: Мои характеристики.
- **Value (V)**: Мой смысл.

## 🎨 Генеративные модели
Модели, которые не просто классифицируют, а создают новое.

1.  **GAN (Generative Adversarial Networks)**: Битва двух сетей. **Генератор** пытается создать подделку, а **Дискриминатор** пытается её отличить от реальности. В этой борьбе они оба становятся профи.
2.  **Diffusion Models (Midjourney, DALL-E)**: Идея в том, чтобы сначала превратить картинку в шум, а потом научить нейросеть восстанавливать картинку из этого шума.

---


## 🔄 Transfer Learning: Философия "Не изобретай велосипед"
В 2024 году никто не обучает огромные сети с нуля.

1. Берем **Pre-trained model** (ResNet для CV, Llama/GPT для NLP).
2. Выполняем **Fine-tuning**: Дообучаем модель на своих маленьких данных.
3. Это экономит миллионы долларов на электричестве и недели времени.

---

| Архитектура | Когда использовать? | Пример |
| :--- | :--- | :--- |
| **CNN** | Картинки, видео | Распознавание лиц |
| **RNN/GRU** | Текст, звук, акции | Переводчик |
| **Transformer** | Текст (крупный), Код | ChatGPT, GitHub Copilot |
| **YOLO** | Обнаружение объектов | Беспилотные авто |

---

> Успех в Deep Learning на 50% состоит из данных, на 30% из архитектуры и на 20% из умения правильно настроить гиперпараметры (Fine-tuning). 🚀
