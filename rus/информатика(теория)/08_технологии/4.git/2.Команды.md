# 2. 🛠️ Команды Git на все случаи жизни

В Git сотни команд, но для эффективной работы достаточно знать около 15-20, понимая их логику.

---


## 1. 🏎️ Базовый рабочий цикл

1. `git status` — **Первое правило Гита**: Если не знаешь что делать, пиши `git status`.
2. `git add <file>` — Перенос изменений в Stage.
3. `git commit -m "feat: description"` — Создание снимка.
4. `git log --oneline --graph --all` — Визуализация истории.

---


## 2. 🚑 Работа над ошибками (Undo)


### 2.1. Исправить последний коммит
`git commit --amend`
Позволяет добавить забытый файл или изменить текст сообщения последнего коммита. Хеш коммита при этом изменится!


### 2.2. Отмена изменений в файле
`git checkout -- <file>` (старый способ) или `git restore <file>` (новый).
Возвращает файл к состоянию последнего коммита. Все несохраненные правки удалятся.


### 2.3. Откат коммитов через Reset
- `--soft`: Удаляет коммит, но **оставляет файлы в индексе (stage)**. Полезно, если вы хотите "переделать" коммит.
- `--mixed` (дефолт): Удаляет коммит, оставляет файлы на диске, но убирает их из индекса.
- `--hard`: **Удаляет всё**. Коммит, файлы из индекса и физические правки. 

> [!CAUTION]
> `reset --hard` — это деструктивная операция. Используйте её только если на 101% уверены.

---


## 3. 🧭 Продвинутая навигация


### 3.1. Reflog — Машина времени
`git reflog`
Git записывает каждое движение `HEAD`. Если вы случайно удалили ветку или сделали `reset --hard` не туда, `reflog` покажет хеш коммита до ошибки. Вы сможете сделать `git checkout <hash>` и спасти код.


### 3.2. Cherry-pick — Выборка
`git cherry-pick <hash>`
Позволяет скопировать один конкретный коммит из любой ветки в текущую.


### 3.3. Stash — Временное хранилище
`git stash` — Спрятать текущие правки "в карман".
`git stash pop` — Достать их обратно.
Полезно, когда нужно срочно переключиться на другую ветку, но текущая работа еще не готова для коммита.


### 3.4. Bisect — Поиск виноватого
`git bisect`
Метод бинарного поиска для нахождения коммита, который сломал сборку. Вы указываете "хороший" коммит и "плохой", а Git водит вас по истории, пока не найдет источник бага.
