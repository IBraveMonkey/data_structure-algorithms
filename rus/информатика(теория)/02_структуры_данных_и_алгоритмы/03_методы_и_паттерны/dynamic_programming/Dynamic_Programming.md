# 💾 Динамическое программирование

**Описание**: 
Динамическое программирование (ДП) — это вершина алгоритмического мастерства. Это метод решения задач, который превращает экспоненциальный хаос в упорядоченную эффективность. Девиз ДП: "Никогда не вычисляй то же самое дважды".

- **Как это устроено внутри**: ДП разбивает задачу на подзадачи, которые перекрываются. Вместо их повторного решения мы записываем ответ в "блокнот" (таблицу или массив).
  - *Мемоизация (Top-Down)*: Решаем рекурсивно, но перед вычислением проверяем — а нет ли уже ответа в кэше?
  - *Табуляция (Bottom-Up)*: Заполняем таблицу от самых маленьких подзадач до глобальной цели (итеративно).
- **Аналогия**: Представьте, что вы строите стену. Чтобы положить 10-й ряд кирпичей, вам не нужно заново пересчитывать, как вы строили первые девять — они уже стоят и служат фундаментом. Вы просто опираетесь на готовый результат предыдущего шага.


### Преимущества и недостатки
✅ **Плюсы**:
1. **Невероятное ускорение**: Позволяет решать за секунды задачи, на которые наивные алгоритмы тратили бы годы.
2. **Оптимальность**: Гарантирует нахождение самого лучшего (минимального или максимального) решения.

❌ **Минусы**:
1. **Расход памяти**: Чтобы помнить все ответы, ДП часто требует создания больших таблиц (массивов или матриц).
2. **Сложность понимания**: Самое трудное в ДП — найти "состояние" и "формулу перехода" (как текущий шаг зависит от предыдущих). Это требует хорошего навыка абстрактного мышления.

---


### Сложность

| Метрика | Сложность (O) |
|:---|:---:|
| Время | O(N * M...) |
| Память | O(N * M...) |

\*N, M — размеры таблицы состояний (State Space).
**Память может быть оптимизирована до O(N) в ряде случаев.


## 🚀 Примеры


### Задача 1: Числа Фибоначчи / Лестница
Нужно найти количество способов подняться на $N$-ю ступеньку, если можно прыгать на 1 или 2 ступеньки. Это классическая задача на DP, логика которой совпадает с числами Фибоначчи.

```go
func ClimbStairs(n int) int {
    if n <= 2 { return n }
    dp := make([]int, n+1)
    dp[1], dp[2] = 1, 2
    for i := 3; i <= n; i++ {
        dp[i] = dp[i-1] + dp[i-2]
    }
    return dp[n]
}
```

```javascript
function climbStairs(n) {
  if (n <= 2) return n;
  let prev1 = 1, prev2 = 2; // Optimization: store only last 2
  for (let i = 3; i <= n; i++) {
    const current = prev1 + prev2;
    prev1 = prev2;
    prev2 = current;
  }
  return prev2;
}
```


### Задача 2: Размен монет (Минимум монет)
Дано целое число `amount` и массив номиналов монет `coins`. Нужно найти минимальное количество монет, необходимых для получения суммы.

```go
func CoinChange(coins []int, amount int) int {
    dp := make([]int, amount+1)
    for i := 1; i <= amount; i++ { dp[i] = amount + 1 } // Max val
    dp[0] = 0
    
    for _, coin := range coins {
        for i := coin; i <= amount; i++ {
            if dp[i-coin]+1 < dp[i] {
                dp[i] = dp[i-coin] + 1
            }
        }
    }
    if dp[amount] > amount { return -1 }
    return dp[amount]
}
```

```javascript
function coinChange(coins, amount) {
  const dp = new Array(amount + 1).fill(amount + 1);
  dp[0] = 0;

  for (const coin of coins) {
    for (let i = coin; i <= amount; i++) {
      dp[i] = Math.min(dp[i], dp[i - coin] + 1);
    }
  }
  return dp[amount] > amount ? -1 : dp[amount];
}
```
