# 👉👈 Два указателя

**Описание**: 
Метод двух указателей — это изящная техника, которая позволяет решать сложные задачи за один проход по данным. Вместо того чтобы использовать вложенные циклы, мы запускаем два индекса ("указателя"), которые движутся навстречу друг другу или с разной скоростью.

- **Как это устроено внутри**: Основная идея — сужение области поиска. Благодаря тому, что указатели двигаются направленно, мы можем отбрасывать ненужные варианты без проверки.
  - *Встречные указатели*: Начинают с концов массива и идут к центру (идеально для поиска палиндромов или пар чисел в отсортированном массиве).
  - *Быстрый и медленный (Заяц и Черепаха)*: Один двигается быстрее другого. Позволяет находить циклы в списках или середину массива.
- **Аналогия**: Представьте, что вы с другом ищете друг друга на длинной улице. Если вы оба пойдете от концов улицы навстречу друг другу, вы встретитесь гораздо быстрее, чем если бы один стоял и ждал, пока другой проверит каждый дом.


### Преимущества и недостатки
✅ **Плюсы**:
1. **Максимальная скорость**: Превращает алгоритмы из медленных O(n²) в быстрые **O(n)**.
2. **Экономия памяти**: Работает напрямую с существующим массивом, не требуя создания копий (O(1) по памяти).
3. **Простота реализации**: После того как логика движения указателей понятна, код обычно получается очень компактным.

❌ **Минусы**:
1. **Зависимость от порядка**: Метод часто требует, чтобы данные были отсортированы. Если это не так, придется сначала потратить время на сортировку.
2. **Узкая специализация**: Подходит только для линейных структур (массивы, строки, связные списки).

## 🚀 Примеры


### Задача 1: Сумма двух чисел (Отсортированный массив)
Найти два числа в отсортированном массиве, которые в сумме дают `target`.

```go
func TwoSumSorted(numbers []int, target int) []int {
    left, right := 0, len(numbers)-1
    for left < right {
        sum := numbers[left] + numbers[right]
        if sum == target {
            return []int{left + 1, right + 1} // Обычно возвращают 1-based индексы
        } else if sum < target {
            left++
        } else {
            right--
        }
    }
    return []int{-1, -1}
}
```

```javascript
function twoSumSorted(numbers, target) {
  let left = 0, right = numbers.length - 1;
  while (left < right) {
    const sum = numbers[left] + numbers[right];
    if (sum === target) return [left + 1, right + 1];
    sum < target ? left++ : right--;
  }
  return [-1, -1];
}
```


### Задача 2: Валидация палиндрома
Проверить, является ли строка палиндромом, игнорируя регистр и небуквенные символы.

```go
import (
    "strings"
    "unicode"
)

func IsPalindrome(s string) bool {
    runes := []rune(strings.ToLower(s))
    left, right := 0, len(runes)-1
    
    for left < right {
        if !unicode.IsLetter(runes[left]) && !unicode.IsNumber(runes[left]) {
            left++
            continue
        }
        if !unicode.IsLetter(runes[right]) && !unicode.IsNumber(runes[right]) {
            right--
            continue
        }
        if runes[left] != runes[right] { return false }
        left++
        right--
    }
    return true
}
```

```javascript
function isPalindrome(s) {
  const cleaned = s.toLowerCase().replace(/[^a-z0-9]/g, '');
  let left = 0, right = cleaned.length - 1;
  while (left < right) {
    if (cleaned[left++] !== cleaned[right--]) return false;
  }
  return true;
}
```
