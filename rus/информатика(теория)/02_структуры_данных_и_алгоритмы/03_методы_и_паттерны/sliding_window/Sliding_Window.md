# 🪟 Скользящее окно

**Описание**: 
Метод скользящего окна (Sliding Window) — это изящный способ превратить медленный перебор во вспышку молнии. Он используется везде, где нужно анализировать непрерывные группы элементов в массивах или строках.

- **Как это устроено внутри**: Вместо того чтобы заново сканировать подмассив для каждой позиции, мы поддерживаем "окно" с помощью двух указателей (`left` и `right`). Когда окно сдвигается вправо, мы просто добавляем новый элемент справа и "выкидываем" старый элемент слева. Это позволяет превратить сложность **O(n*k)** в линейное время **O(n)**.
- **Аналогия**: Представьте, что вы смотрите в окно поезда. Вы видите только определенный участок пейзажа. Когда поезд едет, справа в окне появляются новые деревья, а слева старые деревья исчезают. Вам не нужно выходить из поезда и заново осматривать весь путь от начала до вашего окна — вы просто обновляете картинку перед глазами.


### Преимущества и недостатки
✅ **Плюсы**:
1. **Экстремальная эффективность**: Сокращает количество повторяющихся вычислений до минимума.
2. **Низкое потребление памяти**: Обычно требует лишь несколько переменных для хранения суммы или состояния окна.

❌ **Минусы**:
1. **Только для непрерывных данных**: Метод бессилен, если элементы подмассива разбросаны по всему основному массиву.
2. **Сложность условий**: Иногда бывает трудно правильно настроить момент, когда левая граница должна начать "сжиматься" (особенно в окнах переменного размера).

---


### Сложность

| Метрика | Сложность (O) |
|:---|:---:|
| Время | O(N) |
| Память | O(1) / O(K)* |

\*Если нужно хранить состояние окна (например, частоты символов в хеш-таблице).


## 🚀 Примеры


### Задача 1: Максимальное среднее (Фиксированное окно)
Нужно найти подмассив длиной `k`, среднее арифметическое элементов которого максимально.

```go
func FindMaxAverage(nums []int, k int) float64 {
    sum := 0
    for i := 0; i < k; i++ { sum += nums[i] }
    
    maxSum := sum
    for i := k; i < len(nums); i++ {
        sum += nums[i] - nums[i-k]
        if sum > maxSum { maxSum = sum }
    }
    return float64(maxSum) / float64(k)
}
```

```javascript
function findMaxAverage(nums, k) {
  let sum = 0;
  for (let i = 0; i < k; i++) sum += nums[i];

  let maxSum = sum;
  for (let i = k; i < nums.length; i++) {
    sum += nums[i] - nums[i - k];
    maxSum = Math.max(maxSum, sum);
  }
  return maxSum / k;
}
```


### Задача 2: Минимальный подмассив (Переменное окно)
Найти минимальную длину подмассива, сумма элементов которого $\ge$ `target`.

```go
func MinSubArrayLen(target int, nums []int) int {
    left, sum := 0, 0
    minLen := len(nums) + 1

    for right := 0; right < len(nums); right++ {
        sum += nums[right]
        for sum >= target {
            if right-left+1 < minLen {
                minLen = right - left + 1
            }
            sum -= nums[left]
            left++
        }
    }
    if minLen > len(nums) { return 0 }
    return minLen
}
```

```javascript
function minSubArrayLen(target, nums) {
  let left = 0, sum = 0, minLen = Infinity;

  for (let right = 0; right < nums.length; right++) {
    sum += nums[right];
    while (sum >= target) {
      minLen = Math.min(minLen, right - left + 1);
      sum -= nums[left++];
    }
  }
  return minLen === Infinity ? 0 : minLen;
}
```
