# 🌀 Рекурсия

**Описание**: 
Рекурсия — это один из самых элегантных и в то же время коварных приемов в программировании. Это ситуация, когда функция вызывает саму себя для решения подзадачи меньшего размера.

- **Как это устроено внутри**: Каждый раз, когда функция вызывает себя, в оперативной памяти создается новый "слой" — **фрейм стека**. В нем хранятся локальные переменные этого конкретного вызова. 
  - *Базовый случай*: Это "стоп-кран" рекурсии. Условие, при котором функция перестает вызывать себя и начинает возвращать результат. Без него программа будет плодить вызовы, пока не случится `Stack Overflow` (переполнение стека).
- **Аналогия**: Представьте матрешку. Чтобы достать самую маленькую куколку (результат), вам нужно открыть большую, затем ту, что внутри, и так далее. Вы не можете добраться до центра, не пройдя через все внешние слои. Каждая матрешка — это новый вызов функции.


### Преимущества и недостатки
✅ **Плюсы**:
1. **Чистота кода**: Сложные алгоритмы (например, обход деревьев или быстрая сортировка) записываются очень коротко и понятно.
2. **Естественность**: Многие задачи в математике и природе рекурсивны по своей сути (фракталы, родословные, файловые системы).

❌ **Минусы**:
1. **Расход памяти**: Каждый вызов занимает место в стеке. Если глубина рекурсии слишком большая, память может закончиться.
2. **Риск зависания**: Ошибка в базовом случае превращает рекурсию в бесконечный цикл, который быстро "уронит" программу.
3. **Оверхед**: Вызов функции — это всегда дополнительные затраты ресурсов процессора на создание контекста.

---


### Сложность

| Метрика | Сложность (O) |
|:---|:---:|
| Время | Зависит от количества вызовов |
| Память | O(d) |

\*d — максимальная глубина рекурсии (глубина стека вызовов).


## 🚀 Примеры


### Задача 1: Факториал
Классический пример: $n! = n \times (n-1) \times \dots \times 1$.

```go
func Factorial(n int) int {
    if n <= 1 { return 1 }
    return n * Factorial(n-1)
}
```

```javascript
function factorial(n) {
  if (n <= 1) return 1;
  return n * factorial(n - 1);
}
```


### Задача 2: Бинарный поиск (Рекурсивно)
Поиск элемента в отсортированном массиве путем деления области поиска пополам.

```go
func BinarySearchRecursive(nums []int, target, left, right int) int {
    if left > right { return -1 }
    
    mid := left + (right - left) / 2
    if nums[mid] == target { return mid }
    
    if nums[mid] > target {
        return BinarySearchRecursive(nums, target, left, mid - 1)
    }
    return BinarySearchRecursive(nums, target, mid + 1, right)
}
```

```javascript
function binarySearchRecursive(nums, target, left, right) {
  if (left > right) return -1;

  const mid = Math.floor(left + (right - left) / 2);
  if (nums[mid] === target) return mid;

  if (nums[mid] > target) {
    return binarySearchRecursive(nums, target, left, mid - 1);
  }
  return binarySearchRecursive(nums, target, mid + 1, right);
}
```
