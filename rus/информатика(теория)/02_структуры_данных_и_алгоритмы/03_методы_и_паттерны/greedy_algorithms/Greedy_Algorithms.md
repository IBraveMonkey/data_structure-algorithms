# 🤑 Жадные алгоритмы

**Описание**: 
Жадные алгоритмы (Greedy Algorithms) — это стратегия "жить одним днем". На каждом шаге алгоритм выбирает самый лучший вариант прямо сейчас, надеясь, что сумма этих "лучших" шагов приведет к идеальному итоговому результату.

- **Как это устроено внутри**: Алгоритм никогда не оглядывается назад и не пересматривает свои решения. Он берет локально оптимальный выбор (например, самую крупную монету для сдачи или самый короткий путь) и переходит к следующему подвопросу.
- **Аналогия**: Представьте, что вам разрешили зайти в кондитерскую и взять 5 сладостей. Жадная стратегия — сразу схватить самый большой торт, потом самый большой эклер, и так далее. Это сработает, если ваша цель — набрать максимум веса, но может провалиться, если вы хотите собрать самый сбалансированный набор вкусов.


### Преимущества и недостатки
✅ **Плюсы**:
1. **Простота и скорость**: Эти алгоритмы очень легко придумывать и кодить. Они работают крайне быстро (обычно за O(n log n) из-за сортировки).
2. **Хорошие приближения**: Даже если "жадность" не дает идеального решения, она часто дает результат, который "достаточно хорош" для практики.

❌ **Минусы**:
1. **Отсутствие глобального видения**: Главная беда "жадности" в том, что она может завести в тупик. Локальный успех в начале может обернуться катастрофой в конце.
2. **Ограниченное применение**: Перед использованием нужно математически доказать, что жадная стратегия действительно работает для этой конкретной задачи.

---


### Сложность

| Метрика | Сложность (O) |
|:---|:---:|
| Время | O(N log N)* / O(N)** |
| Память | O(1) / O(N) |

\*O(N log N) если требуется предварительная сортировка.
\*\*O(N) если данные уже отсортированы или сортировка не нужна.


## 🚀 Примеры


### Задача 1: Размен монет (Жадный подход)
Дано целое число `amount` и массив номиналов монет `coins`. Нужно найти количество монет для размена, выбирая каждый раз самый большой номинал.
> [!NOTE]
> Жадный подход для размена монет работает идеально только для определенных наборов номиналов (например, стандартные монеты РФ или США).

```go
func CoinChangeGreedy(coins []int, amount int) int {
    sort.Sort(sort.Reverse(sort.IntSlice(coins)))
    count := 0
    for _, coin := range coins {
        for amount >= coin {
            amount -= coin
            count++
        }
    }
    if amount == 0 { return count }
    return -1
}
```

```javascript
function coinChangeGreedy(coins, amount) {
  coins.sort((a, b) => b - a);
  let count = 0;
  for (const coin of coins) {
    while (amount >= coin) {
      amount -= coin;
      count++;
    }
  }
  return amount === 0 ? count : -1;
}
```


### Задача 2: Выбор интервалов (Interval Scheduling)
Дано множество процессов (интервалов) с временем начала и конца. Нужно выбрать максимальное количество процессов, которые не пересекаются.

```go
type Interval struct {
    Start, End int
}

func MaxNonOverlapping(intervals []Interval) int {
    if len(intervals) == 0 { return 0 }
    
    // Сортируем по времени окончания
    sort.Slice(intervals, func(i, j int) bool {
        return intervals[i].End < intervals[j].End
    })

    count := 1
    lastEnd := intervals[0].End
    for i := 1; i < len(intervals); i++ {
        if intervals[i].Start >= lastEnd {
            count++
            lastEnd = intervals[i].End
        }
    }
    return count
}
```
```javascript
function maxNonOverlapping(intervals) {
  if (intervals.length === 0) return 0;
  
  // Сортируем по времени окончания
  intervals.sort((a, b) => a[1] - b[1]);
  
  let count = 1;
  let lastEnd = intervals[0][1];
  
  for (let i = 1; i < intervals.length; i++) {
    if (intervals[i][0] >= lastEnd) {
      count++;
      lastEnd = intervals[i][1];
    }
  }
  return count;
}
```
