# 📋 Массив (Array)

**Описание**: 
Массив — это фундаментальная структура данных, представляющая собой контейнер для хранения элементов одного типа в **непрерывном блоке памяти**. Это самая простая и эффективная структура для организации данных, когда важна скорость доступа.

- **Как это устроено внутри**: Поскольку элементы лежат в памяти вплотную друг к другу, компьютер может мгновенно вычислить адрес любого элемента по формуле: `адрес_начала + (индекс * размер_типа)`. Именно поэтому доступ по индексу всегда занимает **O(1)** времени.
- **Аналогия**: Представьте шкафчики в раздевалке спортзала. Все они одинакового размера и идут строго по порядку. Если вы знаете номер шкафчика (индекс), вы сразу подходите к нужной дверце.


### Виды массивов
- **Классический (Статический)**: Размер задается один раз при создании. В Go это `[N]T`.
- **Динамический (Срез/Slice)**: Способен "расти". Когда место в текущем массиве заканчивается, структура выделяет новый блок памяти бОльшего размера и копирует туда данные. В Go это `[]T`.


### Преимущества и недостатки
✅ **Плюсы**:
1. **Мгновенный доступ**: Чтение и запись по индексу происходят максимально быстро.
2. **Кэш-дружелюбность**: Поскольку данные лежат подряд, процессору легче предзагружать их в кэш, что ускоряет обработку больших объемов данных.
3. **Экономия памяти**: Минимум накладных расходов — тратится память только на сами данные.

❌ **Минусы**:
1. **Дорогая вставка/удаление**: Если нужно вставить элемент в начало или середину, приходится сдвигать все последующие элементы (O(n)).
2. **Нужна непрерывная память**: Для огромного массива может не найтись одного цельного куска памяти, даже если суммарно свободного места много (фрагментация).
3. **Фиксированный тип**: Все элементы должны быть одного размера.

---


### Основные операции


#### Классический массив:
- Доступ (чтение/запись по индексу)
- Поиск (линейный, если массив не отсортирован)


#### Динамический массив:
- Все операции классического массива плюс:
- Вставка (в конец или в середину)
- Удаление (из конца или середины)


### Сложность

| Операция | Классический массив | Динамический массив |
|:---|:---:|:---:|
| Доступ (по индексу) | O(1) | O(1) |
| Вставка (в конец) | Н/Д | O(1) амортизированная |
| Вставка (в середину) | Н/Д | O(n) |
| Удаление (из конца) | Н/Д | O(1) |
| Удаление (из середины) | Н/Д | O(n) |
| Поиск (неотсортированный) | O(n) | O(n) |
| Хранение | O(n) | O(n) |

> [!NOTE]
> **Доступ O(1)**: Индекс напрямую указывает на ячейку памяти. **Вставка/удаление O(n)**: В середине массива требует сдвига элементов.
> 
> **Н/Д** — операция не применима (например, у классического массива размер зафиксирован при создании, поэтому вставка невозможна).
> 
> **Амортизированная сложность O(1)** — означает, что большинство операций добавления выполняются мгновенно, но изредка (когда место заканчивается) происходит дорогая переаллокация памяти. В среднем (на дистанции) это все равно считается как O(1).

> [!TIP]
> В Go стандартные массивы имеют фиксированный размер, но чаще используются срезы (`[]T`), которые реализуют концепцию динамических массивов.


### Примеры

```go
package main

import "fmt"

func main() {
    // Классический массив (фиксированный размер)
    var classicArr [4]int = [4]int{1, 2, 3, 4}
    fmt.Println("Классический массив:", classicArr)
    
    // Доступ O(1) к элементу
    fmt.Println(classicArr[2]) // Вывод: 3

    // Динамический массив (срез)
    dynamicArr := []int{1, 2, 3, 4}

    // Вставка в конец O(1) амортизированная
    dynamicArr = append(dynamicArr, 5)
    fmt.Println("После добавления элемента:", dynamicArr) // [1 2 3 4 5]

    // Вставка в середину O(n)
    index := 2
    dynamicArr = append(dynamicArr[:index], append([]int{10}, dynamicArr[index:]...)...)
    fmt.Println("После вставки в середину:", dynamicArr) // [1 2 10 3 4 5]
}
```

```javascript
// В JavaScript массивы по умолчанию являются динамическими
const arr = [1, 2, 3, 4];
console.log("Массив:", arr);

// Доступ O(1) к элементу
console.log(arr[2]); // Вывод: 3

// Вставка в конец O(1) амортизированная
arr.push(5);
console.log("После добавления элемента:", arr); // [1, 2, 3, 4, 5]

// Вставка в середину O(n)
const index = 2;
arr.splice(index, 0, 10);
console.log("После вставки в середину:", arr); // [1, 2, 10, 3, 4, 5]
```


### Когда использовать

**Классический массив:**

✅ Нужен быстрый доступ по индексу  
✅ Размер данных точно известен и не изменяется  
✅ Важен контроль использования памяти  
❌ Не подходит, если размер данных может изменяться  

**Динамический массив:**

✅ Нужен быстрый доступ по индексу  
✅ Размер данных может изменяться во время выполнения  
✅ Удобство работы с коллекциями переменного размера  
❌ Меньшая эффективность при частых вставках/удалениях в середину  
❌ Возможные накладные расходы на перераспределение памяти

## 💻 Реализация

```go
package array

import "fmt"

// ArrayExamples демонстрирует базовые операции с массивами и срезами
func BasicOperations() {
	// 1. Объявление массива (фиксированный размер)
	var arr [5]int
	arr[0] = 10 // O(1)

	// 2. Объявление среза (динамический массив)
	slice := []int{1, 2, 3}

	// 3. Добавление в конец (Append)
	// В среднем O(1), но если капасити (capacity) исчерпано,
	// произойдет переаллокация и копирование массива (O(n)).
	slice = append(slice, 4)

	// 4. Вставка в середину (O(n))
	index := 1
	value := 99
	slice = append(slice[:index+1], slice[index:]...)
	slice[index] = value

	// 5. Удаление из середины (O(n))
	// Сохраняем порядок, сдвигая элементы
	slice = append(slice[:index], slice[index+1:]...)

	fmt.Println("Итоговый срез:", slice)
}
```

```javascript
// Базовые операции с массивом в JS
function basicOperations() {
    // 1. Объявление (в JS нет фиксированных массивов в обычном понимании)
    const arr = new Array(5).fill(0);
    arr[0] = 10; // O(1)

    // 2. Создание динамического массива
    let array = [1, 2, 3];

    // 3. Добавление в конец (push)
    // В среднем O(1) амортизированная
    array.push(4);

    // 4. Вставка в середину (O(n))
    const index = 1;
    const value = 99;
    array.splice(index, 0, value);

    // 5. Удаление из середины (O(n))
    array.splice(index, 1);

    console.log("Итоговый массив:", array);
}
```


## 🚀 Пример
```go
package array

import "fmt"

// Examples показывает практические приемы работы с массивами
func Examples() {
	// Реверс массива (In-place)
	// Сложность: O(n) по времени, O(1) по памяти
	data := []int{1, 2, 3, 4, 5}
	for i, j := 0, len(data)-1; i < j; i, j = i+1, j-1 {
		data[i], data[j] = data[j], data[i]
	}
	fmt.Println("Реверс:", data)

	// Поиск максимума
	// Сложность: O(n)
	max := data[0]
	for _, v := range data {
		if v > max {
			max = v
		}
	}
	fmt.Println("Максимум:", max)

	// Фильтрация (создание нового среза)
	// Сложность: O(n)
	even := make([]int, 0)
	for _, v := range data {
		if v%2 == 0 {
			even = append(even, v)
		}
	}
	fmt.Println("Четные:", even)
}
```

```javascript
// Практические приемы
function examples() {
    // Реверс массива (In-place)
    const data = [1, 2, 3, 4, 5];
    data.reverse(); // Встроенный метод, O(n)
    console.log("Реверс:", data);

    // Поиск максимума
    // Сложность: O(n)
    const max = Math.max(...data);
    console.log("Максимум:", max);

    // Фильтрация (создание нового массива)
    // Сложность: O(n)
    const even = data.filter(v => v % 2 === 0);
    console.log("Четные:", even);
}
```
