# 🟢 Покрытие кода (Code Coverage)

Покрытие кода (Coverage) — это метрика, которая показывает, какой процент вашего исходного кода был выполнен во время запуска тестов.


# 1. ❓ Зачем измерять покрытие?

1.  **Поиск "слепых зон"**: Вы видите, какие участки кода (особенно сложные условия `if/else`) никогда не проверялись.
2.  **Удаление мертвого кода**: Если код невозможно покрыть тестами, возможно, он никогда не используется и его можно удалить.
3.  **Оценка качества**: Высокое покрытие не гарантирует отсутствие багов, но низкое точно гарантирует их наличие.


# 2. 🛠️ Команда `go test -cover`

В Go инструменты покрытия встроены прямо в тулчейн.

*   `go test -cover .`: Показывает общий процент покрытия для пакета.
*   `go test -coverprofile=coverage.out ./...`: Запускает тесты и сохраняет детальную информацию в файл.


# 3. 📊 Визуализация покрытия

Цифры в терминале не всегда удобны. Go позволяет сгенерировать HTML-отчет, где вы увидите каждую строку кода.

1.  Сгенерируйте профиль: `go test -coverprofile=cp.out`
2.  Откройте в браузере: `go tool cover -html=cp.out`

В открывшейся странице:
*   **Зеленый цвет**: Код выполнен тестами.
*   **Красный цвет**: Код пропущен.
*   **Серый цвет**: Код, который нельзя протестировать (объявления типов и т.д.).


# 4. ✨ Рекомендации и лучшие практики


### Когда 100% покрытие не имеет смысла?
Стремление к 100% часто приводит к написанию "бесполезных" тестов, которые просто прогоняют код, но ничего не проверяют.

**Примеры, которые сложно или не нужно покрывать на 100%:**
*   Простые геттеры и сеттеры.
*   Обработка фатальных ошибок системы, которые почти невозможно воспроизвести.
*   Код, генерируемый другими инструментами.


### "Золотая середина"
Для большинства проектов хорошим показателем считается **70-80%**. Основное внимание должно быть уделено сложной бизнес-логике, а не вспомогательному коду.

> [!IMPORTANT]
> Качественные тесты важнее количественного покрытия. Покрытие показывает, что строка *была выполнена*, но оно не гарантирует, что она *была проверена на корректность*.
