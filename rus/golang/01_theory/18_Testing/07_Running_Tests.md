# 🏃 Запуск тестов (Running Tests)

Команда `go test` — это мощный инструмент с множеством флагов, которые позволяют управлять процессом тестирования.


# 1. 💻 Базовые команды

*   `go test .`: Запуск тестов в текущей директории.
*   `go test ./...`: Запуск тестов во всех поддиректориях проекта.
*   `go test -v ./...`: Вербозный (подробный) вывод. Показывает названия всех тестов и вывод `t.Log`.


# 2. 🎯 Запуск конкретных тестов

Иногда нужно запустить только один тест или группу тестов, чтобы не ждать остальные.

*   `go test -run TestName`: Запуск теста с конкретным именем.
*   `go test -run TestUser/`: Запуск всех тестов, чье имя начинается с `TestUser`.
*   `go test -run /ValidData`: Запуск всех subtests, соответствующих регулярному выражению.


# 3. ⚡ Параллельное выполнение

Go умеет запускать тесты параллельно, что значительно ускоряет проверку больших проектов.

1.  В коде теста нужно вызвать `t.Parallel()`:
    ```go
    func TestMyFunction(t *testing.T) {
        t.Parallel()
        // ...
    }
    ```
2.  Флаг `-parallel N` ограничивает количество одновременно работающих тестов (по умолчанию равно `GOMAXPROCS`).


# 4. 🚩 Полезные флаги

*   `-count N`: Запустить каждый тест N раз. Полезно для поиска "плавающих" багов (флаг `-count 1` также отключает кэширование тестов).
*   `-timeout 30s`: Установить ограничение по времени. Если тесты идут дольше, они будут принудительно остановлены.
*   `-short`: Указывает тестам, что нужно пропустить долгие сценарии. В коде проверяется через `testing.Short()`.
*   `-failfast`: Остановить выполнение при первом же упавшем тесте.


# 5. 🏷️ Теги сборки (Build Tags)

Позволяют разделять тесты на группы (например, unit и интеграционные).

Добавьте строку в начало файла:
```go
// +build integration
```

Запускайте с флагом:
```bash
go test -tags=integration ./...
```


# 6. 💾 Кэширование тестов

Go кэширует результаты тестов. Если код не менялся, вы увидите `(cached)` в выводе.
Чтобы **очистить кэш**, используйте:
```bash
go clean -testcache
```

> [!TIP]
> Используйте `go test -v -race ./...` при разработке. Флаг `-race` включает детектор состояний гонки (race detector), который помогает найти сложнейшие баги в конкурентном коде.
