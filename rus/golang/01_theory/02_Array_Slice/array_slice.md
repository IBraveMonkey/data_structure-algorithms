# 📦 Массивы и Слайсы в Go

Массивы и срезы (slices) — это фундаментальные структуры данных в Go для работы с последовательностями элементов.

---


# 1. 🏗️ Array (Массив)

**Массив** — это нумерованная коллекция элементов **фиксированной** длины одного типа.


### ⚙️ Ключевые особенности
- **Фиксированный размер**: Размер массива определяется при его создании и является частью его типа (например, `[3]int` и `[5]int` — это разные типы).
- **Передача по значению**: При передаче массива в функцию или присваивании он **копируется целиком**.
- **Память**: Элементы хранятся в памяти непрерывным блоком.

```go
arr := [3]int{1, 2, 3}
var small [2]string = [2]string{"hi", "go"}
matrix := [2][2]int{{1, 2}, {3, 4}}
```

> [!TIP]
> Используйте `[...]int{1, 2, 3}`, если хотите, чтобы компилятор сам определил размер массива на основе количества элементов.

---


# 2. 🧩 Slice (Срез)

**Срез** — это мощная и гибкая обертка над массивом. В отличие от массивов, срезы имеют динамическую длину.


### ⚙️ Внутреннее устройство (Slice Header)
Внутри срез представлен структурой, состоящей из трех полей (3 машинных слова):
1. **Pointer**: Указатель на начало данных в базовом массиве.
2. **Length (len)**: Количество элементов в срезе.
3. **Capacity (cap)**: Емкость — максимальное количество элементов, которое может вместить срез без выделения новой памяти.

```go
type slice struct {
    array unsafe.Pointer // Указатель на массив
    len   int            // Текущая длина
    cap   int            // Емкость
}
```


### 🚀 Механика `append`
Когда вы вызываете `append`, Go проверяет, достаточно ли емкости (`cap`):
1. Если места хватает, элемент просто добавляется в базовый массив, и `len` увеличивается.
2. Если места **мало**:
   - Выделяется новый, более вместительный базовый массив (обычно размер увеличивается в 2 раза, для больших срезов коэффициент меньше).
   - Старые данные копируются в новый массив.
   - Возвращается новый дескриптор среза с обновленным указателем.

> [!IMPORTANT]
> Всегда присваивайте результат `append` обратно переменной: `s = append(s, val)`.

---


# 3. ⚠️ Важные нюансы (Gotchas)


### 🔗 Общий базовый массив
Несколько срезов могут указывать на один и тот же массив. Изменение элемента в одном из них затронет другие.

```go
a := []int{1, 2, 3, 4, 5}
b := a[1:3] // [2 3], ссылается на тот же массив
b[0] = 99   // Теперь a[1] тоже равен 99!
```


### 💧 Утечки памяти
Если вы создаете маленький срез на основе огромного массива и храните его долго, GC не сможет очистить весь массив, так как на него есть ссылка. 
**Решение**: используйте `copy()` в новый срез.

---


# 4. 📊 Сравнение

| Характеристика | Array (Массив) | Slice (Срез) |
| :--- | :--- | :--- |
| **Размер** | Фиксированный (константа) | Динамический (изменяемый) |
| **Передача** | Копирование данных (Costly) | Копирование заголовка (Cheap) |
| **Тип** | Размер — часть типа | Только тип элементов |
| **Использование** | Редко (в основном низкий уровень) | Основной инструмент в Go |

---


# 💡 Пример использования
```go
// Создание с предвыделением памяти (эффективно)
s := make([]int, 0, 10) // len=0, cap=10

// Добавление
for i := 0; i < 5; i++ {
    s = append(s, i)
}

// Копирование
dst := make([]int, len(s))
copy(dst, s)
```
