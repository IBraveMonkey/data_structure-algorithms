# 🧵 Строки в Go

Строка в Go — это **неизменяемая (immutable) последовательность байтов**. Важно понимать: строка — это **не срез (slice)** байтов, хотя они и похожи по поведению. Как правило, в Go строки хранят текст в кодировке **UTF-8**.

---


# 1. 🏗️ Внутреннее устройство

В Go строка (`string`) — это легковесная структура из двух полей (StringHeader):
1. **Pointer**: Указатель на массив байтов (только для чтения).
2. **Length (len)**: Длина строки (количество байтов).

```go
type StringHeader struct {
    Data uintptr
    Len  int
}
```

> [!IMPORTANT]
> В отличие от `slice`, у строки **нет поля Capacity (cap)**. Строка всегда совпадает по размеру с данными, на которые она указывает.


### ⚙️ Ключевые свойства
- **Неизменяемость (Immutability)**: Вы не можете изменить отдельный байт в строке (`s[0] = 'a'` вызовет ошибку компиляции). Любое "изменение" создает новую строку.
- **Связность со срезами**: Преобразование `[]byte(s)` или `string(bytes)` создает копию данных в куче (heap), чтобы гарантировать неизменяемость строки.
- **Сравнение**: Строки можно сравнивать с помощью `==` и `!=`. Это сравнивает содержимое байт за байтом, а не адреса в памяти.

---


# 2. 🔄 Итерация (Два пути)

В Go итерация по строке работает по-разному в зависимости от способа.


### 🔢 С помощью простого `for` (по байтам)
Когда вы используете классический цикл `for i := 0; i < len(s); i++`, вы достаете **байты**.

```go
s := "Привет"
for i := 0; i < len(s); i++ {
    fmt.Printf("%x ", s[i]) // Выведет HEX-коды байтов UTF-8
}
```


### 🔤 С помощью `range` (по рунам)
Цикл `range` автоматически декодирует UTF-8 и выдает **руны** (`rune` — тип-алиас для `int32`, представляющий Unicode-символ).

```go
s := "Привет"
for index, runeValue := range s {
    fmt.Printf("%d: %c ", index, runeValue)
}
```

> [!CAUTION]
> При итерации через `range` индексы могут "прыгать" (например, 0, 2, 4...), так как один символ в UTF-8 может занимать несколько байтов.

---


# 3. 🧩 Rune (Руна)

**Руна** — это Unicode-символ (Code Point).
- В Go `rune` — это синоним `int32`.
- Если вам нужно работать с символами (например, перевернуть строку или посчитать количество букв), всегда преобразуйте строку в `[]rune`.

```go
s := "Gopher"
runes := []rune(s)
fmt.Println(len(runes)) // Вернет количество СИМВОЛОВ, а не байтов
```

---


# 4. 🚀 Эффективность

- **Copying**: Копирование строки очень дешево (копируется только заголовок — указатель и длина).
- **Slicing**: Получение подстроки `s[1:4]` также дешево, так как новая строка указывает на ту же область памяти в базовом массиве байтов.
- **Concat**: Сложение строк через `+` эффективно для небольших объемов. Для сборки больших строк из множества частей используйте `strings.Builder`.

---


# 📊 Сводка

| Операция | Результат |
| :--- | :--- |
| `len(s)` | Количество **байтов** |
| `s[i]` | **Байт** по индексу |
| `for r := range s` | Итерируется по **рунам** (Unicode символам) |
| `[]rune(s)` | Преобразование в массив символов (дорого) |
| `[]byte(s)` | Преобразование в массив байтов (дорого) |
