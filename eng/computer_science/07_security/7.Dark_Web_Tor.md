The internet we see is the tip of the iceberg. The majority of data (Deep Web) is hidden behind passwords, while a part (Dark Web) is intentionally concealed within overlay networks invisible to standard browsers. Tor is the most well-known tool for accessing this shadow realm.

## 1. 🧊 Layers of the Internet
*   **Surface Web (4%)**: The indexed part. Google, Wikipedia, Media. Accessible to everyone.
*   **Deep Web (90%)**: The unindexed part. Corporate databases, your private emails, site admin panels, bank transactions. Cannot be accessed via a direct link without authorization.
*   **Dark Web (6%)**: Hidden networks (Darknets) that run on top of the regular internet but require special software (Tor, I2P, Freenet). They use pseudo-domains like `.onion` which are not registered in DNS.

---


## 2. 🧅 Tor Architecture (The Onion Router)
Tor ensures anonymity by wrapping a data packet in multiple layers of encryption (like an onion) and passing it through a chain of three random volunteer nodes.


### Circuit Construction
1.  **Entry Node (Guard)**: The entry point. It knows your real IP address but doesn't know where you are going or what you are transmitting (data is encrypted). Only trusted servers operating for years are selected as Guard nodes (to avoid Sybil attacks).
2.  **Middle Node**: The intermediate hop. It only knows the address of the previous and next node. It knows neither you nor the destination site.
3.  **Exit Node**: The final point. It peels off the last layer of encryption and sends the request to the site. It sees **where** and **what** you are sending (unless HTTPS is used) but doesn't know **who** you are.


### Hidden Services (Onion Services)
Sites within the `.onion` zone operate differently. Neither the client nor the server knows each other's IP addresses.
1.  The server selects several nodes in the Tor network as **Introduction Points**.
2.  The client selects a **Rendezvous Point**.
3.  Through an encrypted tunnel, they "meet" at this point and exchange data. There is no end-to-end connection. This ensures anonymity for both the reader and the site author.

---


## 3. 🛡️ Censorship Circumvention and Bridges
In countries with strict internet censorship (China, Iran), public Tor node IP addresses are blocked.
To access the network, **Bridges** are used—secret nodes whose addresses are not published in public lists.
To prevent the ISP (DPI) from realizing you are using Tor, **Pluggable Transports** (e.g., `obfs4`) are employed. These algorithms mask encrypted traffic as "noise" or a standard HTTPS call, making it indistinguishable from random data.

---


## 4. 🕵️ Attacks on Anonymity
Tor is not perfect. The most dangerous threat is the **Correlation Attack (Traffic Analysis)**.
If an intelligence agency controls both the Entry and Exit nodes (or the ISP backbone on both ends), it can correlate packet timings.
*   "At 12:00:01 User A sent a 5KB packet."
*   "At 12:00:03 Site B received a 5KB packet."
With high probability, A visited B. Mass surveillance of this level requires state-scale resources.
