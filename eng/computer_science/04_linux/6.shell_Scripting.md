## 1. 🚇 Pipeline (Pipe |)

Passes the output of one command as the input to another.
`ls | grep ".go" | wc -l`

---


## 2. 🌊 Redirection

- `>`: Overwrite the file with the output.
- `>>`: Append the output to the end of the file.
- `2>&1`: Redirect standard error (stderr) to the same location as standard output (stdout).
