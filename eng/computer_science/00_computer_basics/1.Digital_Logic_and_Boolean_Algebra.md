## 1. 📐 Boolean Algebra

Boolean algebra is a branch of mathematics that deals with logical values (**TRUE/1** and **FALSE/0**) and operations performed on them.

| Operation | Notation | Description | Result is 1 if... |
|:---|:---:|:---|:---|
| **AND** | A ∧ B | Logical AND | Both A and B are 1 |
| **OR** | A ∨ B | Logical OR | At least one of A or B is 1 |
| **NOT** | ¬A | Inversion | A = 0 |
| **NAND** | ¬(A ∧ B) | Negated AND | Not all inputs are 1 |
| **NOR** | ¬(A ∨ B) | Negated OR | All inputs are 0 |
| **XOR** | A ⊕ B | Exclusive OR | Exactly one input is 1 |

### Boolean Laws 📚

| Law | Example |
|:---|:---|
| **Commutative** | A ∧ B = B ∧ A, A ∨ B = B ∨ A |
| **Associative** | (A ∧ B) ∧ C = A ∧ (B ∧ C) |
| **Distributive** | A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C) |
| **De Morgan's** | ¬(A ∧ B) = ¬A ∨ ¬B, ¬(A ∨ B) = ¬A ∧ ¬B |
| **Idempotent** | A ∧ A = A, A ∨ A = A |

> [!TIP]
> **Application**: Simplifying logical expressions to optimize circuits and design digital devices (e.g., processors).

> [!NOTE]
> **Simplification Example**: Let's simplify A ∧ (A ∨ B).
> 
> Using the distributive law: A ∧ (A ∨ B) = (A ∧ A) ∨ (A ∧ B) = A ∨ (A ∧ B)
> 
> Then: A ∨ (A ∧ B) = A (Absorption Law)

## 2. 🧩 Combinational Logic

Combinational logic refers to circuits where the output depends **only on the current inputs**, without regard to previous states.


### Core Elements


#### Adder

Adds binary numbers.

- **Half Adder**: Adds two bits, producing a sum and a carry.
- **Full Adder**: Adds two bits while accounting for an input carry.

#### Demultiplexer (DEMUX)

Directs a single input signal to one of several outputs.


#### Decoder / Encoder

- **Decoder**: Converts binary code into a signal on one of its outputs (e.g., `00` → output 0, `01` → output 1).
- **Encoder**: The inverse of a decoder; converts a signal into binary code.

> [!IMPORTANT]
> In a processor, adders are used in the **ALU** (Arithmetic Logic Unit) to perform addition, subtraction, and other arithmetic operations.


- Bit 0: `1 + 1 = 10` → sum=0, carry=1

> A processor uses a chain of **full adders** (typically 32 or 64 for modern processors), each adding one bit with carry. This all happens in **nanoseconds**!

Sequential logic refers to circuits where the output depends on **current inputs AND previous states** (memory).

## 4. 🤖 Finite State Machines

A **Finite State Machine (FSM)** is a model describing the behavior of a system with a limited number of states.


### Components 🧱

- **States**: E.g., "on", "off".
- **Transitions**: Conditions under which the system changes state (e.g., "button pressed").
- **Inputs**: Signals that trigger transitions.
- **Outputs**: Results that depend on the state or inputs.

### Types 🎨

| Type | Description | Output Depends On |
|:---|:---|:---|
| **Moore Machine** | Output depends exclusively on the current state | State only |
| **Mealy Machine** | Output depends on both current state and inputs | State + inputs |


### Applications 🚀

- Process management in CPUs.
- Communication protocols (e.g., USB, TCP/IP).
- Game logic.
- Device control.

> [!TIP]
> **Example**: A processor uses FSMs to manage the **instruction pipeline** (Fetch → Decode → Execute → Write Back).

**From physical press to digital signal:**

```mermaid
linkStyle default stroke:#009688,stroke-width:2px;




```

**Detailed process:**

1. **Physical press**:
   - Finger presses key → spring compresses
   - Metal contacts touch

2. **Electrical signal**:
   - Before press: resistor "pulls up" line to 5V (logic **1**)
   - After press: contact grounds to 0V (logic **0**)
   - Or vice versa, depending on circuit (active low/high)

3. **Bounce problem**:
   ```
   Ideal signal:     _____|‾‾‾‾‾‾‾‾‾
   Real signal:      _____|‾|_|‾|_|‾‾‾  (contacts "bounce")
   ```
   - Physical contact **"bounces"** for ~1-10 ms
   - Creates false 0→1→0→1 transitions

4. **Solution — debounce circuit**:
   - **Schmitt trigger**: Has two switching thresholds (e.g., 1.5V and 3.5V)
     - Transition 0→1: only when voltage > 3.5V
     - Transition 1→0: only when voltage < 1.5V
     - **Hysteresis** prevents false triggers
   - Or **RC filter + trigger**: Capacitor smooths spikes
   - Or **software debounce**: Controller ignores changes faster than 20 ms

5. **State storage**:
   - **D flip-flop** captures stable signal on clock pulse
   - Flip-flop output = "key pressed" (1) or "released" (0)

6. **Matrix scanning**:
   - Keyboard controller scans matrix (e.g., 6 rows × 18 columns)
   - Determines pressed key coordinates
   - Generates scan code and sends via USB

**USB connection is managed by a finite state machine:**


**Detailed flash drive connection process:**

1. **State: Detached**
   - USB port monitors D+/D- lines (both low)

2. **Transition → Powered**
   - You insert flash drive → D+ line pulls up to 3.3V (via 1.5kΩ resistor)
   - Host detects **voltage change** → begins supplying 5V on power line

3. **Transition → Default**
   - Host sends **reset signal** (SE0: D+ and D- = 0V for 10 ms)
   - Device gets temporary address **0**
   - Host requests **device descriptor** (what are you? storage, keyboard, mouse?)

4. **Transition → Address**
   - Host assigns unique address (e.g., **3**)
   - Device responds with acknowledgment (**ACK**)

5. **Transition → Configured**
   - OS loads driver (for flash drive: mass storage driver)
   - Device ready: appears as drive **E:**

6. **Transition → Suspended**
   - If inactive > 3 ms → power saving mode
   - Consumption drops to 2.5 mA

7. **Transition → Detached**
   - You remove flash drive → D+ line drops to 0V
   - Host detects disconnection
