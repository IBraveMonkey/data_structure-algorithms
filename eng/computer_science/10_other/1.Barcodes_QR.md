# 🏁 Barcodes and QR Codes: Data Encoding Technologies

Automatic Identification Systems (Auto-ID) form the backbone of global logistics and retail. They allow physical objects to be translated into digital format in fractions of a second with minimal error probability.

## 1. 📏 Linear Barcodes (1D)
A linear barcode is a sequence of black and white bars that encode binary information. The most widespread standard globally is **EAN-13** (European Article Number).


### How EAN-13 Works
The barcode consists of 95 modules (the narrowest bars).
*   **Start/Stop Pattern**: Three bars at the beginning and end (101), telling the scanner where the code starts and finishes.
*   **L-R Coding**: The left and right halves of the code use different encoding patterns (parity). This allows the scanner to determine orientation: even if a cashier scans an item upside down, the laser interprets the digit sequence correctly.
*   **GTIN (Global Trade Item Number)**: A unique item number. The first 2-3 digits are the country prefix (e.g., 00-13 for USA/Canada), followed by the manufacturer code, then the product code.


### Checksum
The final, 13th digit is calculated mathematically from the first 12 digits. The scanner performs this calculation in real-time: if the computed sum doesn't match the read digit, it won't "beep," preventing the sale of an incorrect item.

## 2. ⬛ 2D Matrix Codes: QR (Quick Response)
Linear codes are limited (max 10-20 characters). QR codes, developed by Denso Wave in 1994, use a matrix of dots and can encode up to 7,089 numbers or 4,296 alphanumeric characters.


### Structure and Navigation
1.  **Finder Patterns**: Three large squares in the corners. They define the coordinate system, allowing the code to be read from any angle and distance.
2.  **Alignment Patterns**: Smaller squares inside the code that help compensate for perspective distortion or surface curvature (e.g., on a round can).
3.  **Timing Patterns**: Alternating black and white dots connecting the finder patterns. They define the grid scale so the scanner understands the size of a single module.


### Error Correction (Reed-Solomon)
QR codes have built-in redundancy based on Reed-Solomon codes (technology used in CDs/DVDs and satellite communication). This allows data recovery even if part of the code is destroyed.

There are 4 correction levels (chosen at creation):
*   **Level L (Low)**: Recovers ~7% of data. Used when the code needs to be as clean as possible.
*   **Level M (Medium)**: ~15%. The standard for most marketing codes.
*   **Level Q (Quartile)**: ~25%.
*   **Level H (High)**: Recovers up to 30% damage. The code size (number of dots) increases, but these codes can be branded by placing a logo in the center—overlaping part of the data while keeping the code readable.


### QR vs. Data Matrix
*   **QR Code**: Optimized for fast reading by smartphone cameras. Popular in marketing and payments.
*   **Data Matrix**: More compact for small data volumes. Does not have large corner "eyes" (uses an L-shaped finder pattern). The de facto standard for industrial marking (microchips, pharmaceuticals), as it can be laser-etched onto a 2x2 mm area.
